GITHUB RELEASE SETUP
====================

Repository:
  https://github.com/willmantra/video-downloader

The app checks the repository's latest GitHub Release for updates.

CURRENT BASELINE
================
Version 0.4.2 bundles yt-dlp, FFmpeg and ffprobe inside the installed application.
Users should not need to install those tools separately or add them to Windows PATH.

Create and push the matching tag:

  git tag v0.4.2
  git push origin v0.4.2

The GitHub Actions workflow will then:
- build the application as a PyInstaller onedir distribution;
- download yt-dlp and FFmpeg into the application's bin folder;
- package the complete folder with Inno Setup;
- create VideoDownloaderSetup-0.4.2.exe;
- create a SHA-256 checksum file;
- publish both files in the GitHub Release.

FUTURE UPDATES
==============
For each future version:

1. Update version.txt, for example:
   0.5.0

2. Make and test the code changes.

3. Commit and push them to main.

4. Tag that exact version and push the tag:
   git tag v0.5.0
   git push origin v0.5.0

5. GitHub Actions builds and publishes the installer and checksum automatically.

6. Existing installed copies can detect the newer release and offer the update.

NOTES
=====
- The tag MUST match version.txt: version.txt 0.5.0 = tag v0.5.0.
- The repository must remain public for anonymous update checks.
- Release builds use PyInstaller onedir rather than onefile.
- The updater verifies the published SHA-256 checksum before launching an installer.
- bundle_dependencies.ps1 supplies yt-dlp, ffmpeg.exe and ffprobe.exe for release and local builds.
