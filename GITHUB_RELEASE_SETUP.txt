ONE-TIME SETUP FOR AUTOMATIC APP UPDATES
========================================

The app is already configured to check:
  https://api.github.com/repos/willmantra/video-downloader/releases/latest

1. On GitHub, create a PUBLIC repository named:
   video-downloader

2. Put the contents of this project folder into that repository, including:
   .github\workflows\release.yml

3. Commit and push the files to the main branch.

4. Create the first release by tagging the current version and pushing the tag:

   git tag v0.4.0
   git push origin v0.4.0

5. GitHub Actions will automatically:
   - build Video Downloader.exe on a Windows runner;
   - build VideoDownloaderSetup-0.4.0.exe;
   - create a GitHub Release;
   - attach both files to that release.

6. Once that release exists, Help > Check for updates in the app will use GitHub Releases automatically.

FUTURE UPDATES
==============
For each future version:

1. Change version.txt, for example:
   0.5.0

2. Make the code changes and commit them.

3. Tag that exact version and push it:
   git tag v0.5.0
   git push origin v0.5.0

4. GitHub Actions builds and publishes the installer automatically.

5. Existing installed copies will detect v0.5.0 on startup (or via Help > Check for updates), offer the update, install it and reopen.

NOTES
=====
- The tag MUST match version.txt: version.txt 0.5.0 = tag v0.5.0.
- The repository must be public for anonymous update checks. A private repository would require authentication/token handling in the app.
- Release notes generated by GitHub are shown in the app's update prompt.
